# YouTube 視聴履歴 & チャンネル一覧 (YouTube Channel Saver)

Chrome 拡張機能 (Manifest V3)。視聴した YouTube 動画をサイドパネルで一覧管理し、チャンネル一覧の保存もできるツールです。

## 機能

- **視聴履歴の自動記録** — YouTube を視聴すると、拡張機能のサイドパネルに動画が自動的に記録されます（サムネイル付き）。
- **並べ替え** — 「新しい順 / 古い順」をワンクリックで切り替え。
- **絞り込み** — タイトルで履歴を検索・フィルタリング。
- **削除** — 個別削除および全消去に対応。
- **書き出し** — 履歴をテキストファイルにエクスポート。
- **チャンネル一覧の保存** — アクティブな YouTube タブのサイドバーから、登録チャンネルなどのチャンネル一覧を保存できます。

## インストール（開発者モード）

1. Chrome を開き、`chrome://extensions/` にアクセスします。
2. 右上の「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を選択し、このフォルダ（`youtube-channel-saver`）を選択します。

## 使い方

1. ツールバーの拡張機能アイコンをクリックするとサイドパネルが開きます。
2. YouTube で動画を視聴すると、履歴がパネルに表示されます。
3. ツールバーのボタンで並べ替え・書き出し・全消去、検索ボックスで絞り込みができます。
4. YouTube のタブを開いた状態で「チャンネル一覧保存」を押すと、サイドバーのチャンネル一覧が保存されます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `background.js` | Service Worker（サイドパネルの制御など） |
| `content.js` | YouTube ページ内で動画情報を取得するコンテンツスクリプト |
| `sidepanel.html` / `sidepanel.css` / `sidepanel.js` | サイドパネルの UI |

## パーミッション

- `scripting`, `tabs` — アクティブな YouTube タブへコンテンツスクリプトを実行するため
- `storage` — 履歴とチャンネル一覧の保存のため
- `sidePanel` — サイドパネルの表示のため
- ホスト権限は `https://www.youtube.com/*` のみで、データはブラウザ内（`chrome.storage`）に保存されます。
